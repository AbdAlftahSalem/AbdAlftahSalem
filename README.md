## 🧰 Open source

- 📱 **[flutter-remote](https://github.com/AbdAlftahSalem/flutter_remote)** [![npm](https://img.shields.io/npm/v/flutter-remote?logo=npm&label=npm)](https://www.npmjs.com/package/flutter-remote): run your Flutter app in a real iOS Simulator from Windows or Linux, no Mac. Builds on a GitHub macOS runner and streams the Simulator to your browser over WebRTC.
- 🖼️ **[store_screenshots](https://github.com/AbdAlftahSalem/store_screenshots)** [![pub package](https://img.shields.io/pub/v/store_screenshots?logo=dart&label=pub.dev)](https://pub.dev/packages/store_screenshots): store-ready App Store & Google Play screenshots from Flutter widget tests: every device × every locale, frames, ARB captions, RTL. No emulator.
- 🌐 **[transly](https://github.com/AbdAlftahSalem/transly)** [![pub package](https://img.shields.io/pub/v/transly?logo=dart&label=pub.dev)](https://pub.dev/packages/transly): check, fix and auto-translate Flutter ARB/JSON localization files: missing keys, placeholder & ICU mismatches, unused and hardcoded strings, CI mode. 173 tests · pana 160/160.
- 🗄️ **[cache_nexus](https://github.com/AbdAlftahSalem/cache-nexus)** [![pub package](https://img.shields.io/pub/v/cache_nexus?logo=dart&label=pub.dev)](https://pub.dev/packages/cache_nexus): offline-first data layer for Flutter: TTL caching, 5 cache policies, AES-GCM encryption, reactive streams, offline sync.
- ⚡ **[Thunder CLI](https://github.com/AbdAlftahSalem/Thunder-CLI)** [![pub package](https://img.shields.io/pub/v/thunder_cli?logo=dart&label=pub.dev)](https://pub.dev/packages/thunder_cli): scaffolds Flutter apps with GetX and a clean MVC structure in minutes.
- 📚 **[Thunder API](https://github.com/AbdAlftahSalem/Build-API-Collection)** [![pub package](https://img.shields.io/pub/v/thunder_api?logo=dart&label=pub.dev)](https://pub.dev/packages/thunder_api): generates API collections and route files from annotated code.
- 🔐 **[Thunder Encryption](https://github.com/AbdAlftahSalem/Thunder-Encryption)** [![pub package](https://img.shields.io/pub/v/thunder_encryption?logo=dart&label=pub.dev)](https://pub.dev/packages/thunder_encryption): encryption and decryption utilities for Dart and Flutter.
